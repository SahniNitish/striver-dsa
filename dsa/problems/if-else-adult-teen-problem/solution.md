# If Else Adult Teen Problem

## Problem Description
Given an integer age, print on the screen:Adult if age >= 18Teen if age < 18Do not change the case of any letter in "Adult" and "Teen" while printing the answer.For printing use:-for C++ : cout << variable_name<<endl;for Java : System.out.println();for Python : print()for Javascript : console.log()

## Solution

```python
class Solution:
    def isAdult(self, age):
        if age >= 18:
            print("Adult")
        else:
            print("Teen")
```
